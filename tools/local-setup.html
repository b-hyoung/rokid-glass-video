로컬 PC에 안경 연결

안경 실시간 제어 · 사진·녹화 인식 테스트

  1. 안경과 PC를 같은 Wi-Fi에 연결합니다.
  2. PC의 Chrome에서는 로컬 제어 화면을 엽니다. PC에서는 localhost 주소를 사용하세요.
  3. ADB로 안경 앱의 서버 주소를 아래 PC 주소로 지정합니다. 앱을 다시 설치할 필요는 없습니다.
  4. 로컬 제어 화면에서 안경 촬영 시작을 누르고, WebRTC를 선택해 영상을 확인합니다.

PC 주소 확인 중…

ADB가 인식한 안경이 연결돼 있어야 합니다. PC의 Windows 방화벽에서 Node.js의 개인 네트워크 연결이 허용돼 있어야 합니다. 안경 실물 연결은 이 조건을 갖춘 뒤 확인할 수 있습니다.


자동 서버 선택으로 돌아가려면:
adb shell am force-stop com.hoonartis.glassvideo
adb shell am start -n com.hoonartis.glassvideo/.MainActivity -d auto


서버를 다시 켜려면 프로젝트 폴더의 start-local.cmd를 실행하세요. 등록 사진과 벡터는 PC의 runtime/local-state에 보관됩니다.
