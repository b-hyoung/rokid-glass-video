영상 연결 준비 중

선택 후 촬영 시작을 누르면 적용됩니다. 40fps는 요청값이며, 기기가 지원하는 범위와 조명에 따라 실제 속도가 달라질 수 있습니다.

촬영 시작 시 적용됩니다. 프레임은 유지하고 전송량을 줄입니다.

인식 중에는 이 웹을 열어 두세요. 안경 촬영 영상만 사용하며 Mac 카메라는 사용하지 않습니다.

    외부 사진으로 등록

    안경 연결이나 벡터 파일 없이 사진만 등록할 수 있습니다. 같은 물체의 여러 각도를 선택하세요. 사진 전체가 참조 이미지로 저장되므로 물체가 크게 보이고 배경이 적은 사진을 사용하세요.

    PC에서 벡터와 사진 등록

    벡터 JSON 1개와 참조 사진이 담긴 대상 폴더를 선택하세요. 사진은 같은 대상의 등록 이미지에 추가됩니다.

    3 · 인식 실행

    인식 엔진 준비 중

    사진과 벡터를 함께 등록한 물체는 카메라 시야에서 두 결과가 일치하면 조준하기 전에도 안경에 ▶와 이름이 표시됩니다. 표시된 물체에 조준점을 2.5초 유지하면 연결 영상이 재생됩니다. 재생 중에는 다른 대상의 영상이 시작되지 않습니다. 안경 버튼으로 영상을 종료한 뒤 중앙을 비우고 다시 조준하세요. 같은 대상을 다시 재생하려면 시야 밖으로 2초 이상 벗어나게 하세요.
