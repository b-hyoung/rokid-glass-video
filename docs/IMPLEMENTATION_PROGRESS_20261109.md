## 로컬 후보와 APK

현재 PC에 `python tools/start_local.py --port 8790 --no-open`으로 별도 로컬 후보를 실행했다. 접속: http://localhost:8790/recognition, 파일 시험: http://localhost:8790/local-check.html. 이 포트는 runtime/local-state-8790을 사용한다. 초기 데이터는 보관된 사본이며 운영 최신 상태라고 주장하지 않는다.

후보 APK는 build/glass-video-0.2.20-candidate.apk, versionCode 22, 프로토콜 1이다. 이번 바이너리는 이 PC의 8790 LAN 서버를 기본/자동 탐색 주소로 넣어 빌드했다. 기존 앱에서 주소를 pin한 설정은 그대로 우선한다. APK 옆 JSON에 실제 주소, APK 해시, 서명 인증서 지문을 기록한다.

후보 인증서는 보관 0.2.19 tracking-test와 일치한다. 실제 안경 설치본의 인증서를 확인한 것은 아니다. certificateSha256은 release.json에서 미승인(null)으로 유지한다. 후보 APK를 정식 다운로드로 옮기거나 기존 설치를 삭제하지 않았다. 안경에 새 통신 구현을 적용하려면 후보 APK 업데이트와 기기 확인이 필요하다.
